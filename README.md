## 🎯 My Problem-Solving Approach

I follow a structured approach whenever I solve a coding problem:

1. **Visualize the Problem** – First, I visualize the problem and try to understand how it works.
2. **Understand the Logic** – I break the problem into smaller parts and identify what needs to be solved.
3. **Think of a Brute-Force Approach** – Before coding, I work out a basic solution on paper.
4. **Implement the Solution** – I convert my approach into Java code.
5. **Improve My Logic** – I analyze my solution and explore ways to make it better.
